para el día a día.

nuevas funciones y amplía NOVA FLOW hasta 40 modos de

------------------------------------------------------------
                    INSTALACIÓN
------------------------------------------------------------

1. Crear un repositorio en GitHub.

2. Subir estos archivos:

   index.html
   style.css
   script.js
   manifest.webmanifest
   sw.js
   README.txt

3. Activar GitHub Pages.

4. Abrir la dirección de la página.

5. Desde un navegador compatible se podrá instalar
   ÚtilHub como aplicación.

------------------------------------------------------------
                 FUNCIONAMIENTO SIN INTERNET
------------------------------------------------------------

El archivo sw.js utiliza un Service Worker para guardar
los archivos principales de ÚtilHub.

Esto permite que la aplicación pueda cargar parte de su
contenido incluso cuando no exista conexión a Internet.

Las funciones que necesitan servicios externos pueden
requerir conexión.

------------------------------------------------------------
                  DATOS DEL USUARIO
------------------------------------------------------------

ÚtilHub guarda determinadas preferencias y datos localmente
en el navegador mediante localStorage.

Esto puede incluir:

• Tema.
• Favoritos.
• Herramientas recientes.
• Notas.
• Tareas.
• Listas.
• Configuración de NOVA FLOW.
• Preferencias de rendimiento.

Los datos no necesitan una cuenta para funcionar.

------------------------------------------------------------
                  COMPRAS Y COMIDA
------------------------------------------------------------

Las herramientas de compras y comida ayudan al usuario a
encontrar opciones o acceder a servicios externos.

ÚtilHub NO realiza pedidos automáticamente.

El usuario decide qué comprar o pedir y completa la acción
directamente en el servicio correspondiente.

------------------------------------------------------------
                  PRIVACIDAD
------------------------------------------------------------

ÚtilHub V20 está diseñado para funcionar principalmente
desde el navegador.

Las funciones que utilizan servicios externos pueden enviar
la información necesaria a dichos servicios para realizar
la función solicitada.

No introducir información privada innecesaria.
